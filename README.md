# Shanghai Bus Operations

Public-data research project for sampling and analyzing selected Shanghai bus routes using anonymously accessible SHMAAS public-transport endpoints.

## Scope

Initial routes: 浦东78路、浦东35路、182路。

The repository stores sampled public-transport observations and derived operational estimates. Derived arrival times, short-turn classifications, confidence levels and rankings are analytical results and may contain sampling or inference error.

## Data and privacy

- No account credentials, cookies or private API keys are required by the SHMAAS sampler.
- Legacy third-party probing code and historical private-repository diagnostics are intentionally excluded.
- Vehicle license plates may appear because they are returned by the public transport data source and are used to distinguish operating vehicles.

## Disclaimer

This is an independent, unofficial research project and is not affiliated with Shanghai MaaS or any public transport operator. Data availability and accuracy are not guaranteed.
